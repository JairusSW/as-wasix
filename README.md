## Installation

```bash
npm install as-wasix
npm install -D @assemblyscript/wasi-shim
```

## Quick Start

```ts
import { fs, thread, proc, ensureOk } from "as-wasix";

ensureOk(thread.sleep(0), "thread.sleep");
ensureOk(proc.snapshot(), "proc.snapshot");

const cwdBuf = new Uint8Array(256);
const cwdLen = new Uint32Array(1);
cwdLen[0] = cwdBuf.length;

const errno = fs.getcwd(changetype<i32>(cwdBuf.dataStart), changetype<i32>(cwdLen.dataStart));
ensureOk(errno, "fs.getcwd");
```

## API Overview

- Raw WASIX imports are exported (e.g. `proc_snapshot`, `sock_open`, etc.)
- User-facing namespaces are exported for organized consumption
- Most functions return `Errno` (`i32`)
- Out values are returned via pointer parameters (`out*Ptr`)
- Selected helpers accept `string` and encode internally (for example `fs.changedir`, `proc.exec`, `proc.spawn`, `asyncRuntime.callbackSignal`)

## Namespace Modules

- `clock`: clock operations
- `fs`: filesystem and FD operations
- `thread`: multithreading and futex operations
- `asyncRuntime`: callback signal and epoll operations
- `jump`: setjmp/longjmp stack checkpoint and restore
- `proc`: process operations (snapshot, fork, spawn, exec, signals)
- `subprocess`: subprocess-focused aliases for spawn/join/signal
- `tty`: terminal state operations
- `net`: networking, ports, sockets, and name resolution
- `dynamic`: dynamic loading and dynamic call helpers

## Bindings Generation

Bindings are generated by cloning the upstream WASIX Rust ABI repository.

```bash
npm run generate:bindings
```

- Source (cloned at generation time): `https://github.com/wasix-org/wasix-abi-rust` (`src/lib_generated32.rs`)
- Output: `assembly/bindings/wasix_32v1.ts`

## Development

```bash
npm run asbuild
npm test
npm run verify
```

`npm run verify` will regenerate bindings, build all targets, and run CI-style tests.

## Testing

`as-test` runs tests with Wasmer (`wasmer run <file>` in `as-test.config.json`).

Current suite includes:

- Behavioral tests for namespace usage
- Exhaustive export checks for all raw imports and namespace functions
